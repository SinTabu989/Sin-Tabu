# Sin-Tabu
Página web educativa desarrollada para Sin Tabú, un proyecto enfocado en brindar información clara, segura y comprensible sobre educación sexual y salud integral para adolescentes en adelante. 
## Problemática de la comunidad
En la comunidad existe desinformación y falta de acceso a información clara sobre educación sexual, lo que puede generar dudas, prejuicios y decisiones poco informadas.

Sin Tabú busca brindar información educativa, sencilla y confiable para que los adolescentes puedan aprender sobre sexualidad y cuidado personal sin prejuicios.
